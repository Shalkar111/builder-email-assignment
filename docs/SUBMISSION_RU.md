# Что сдавать

GitHub: https://github.com/Shalkar111/builder-email-assignment

В Moodle нужно загрузить `output/pdf/Assignment_1_Builder_Report.pdf`.
В нём указаны Шалкар, SE-2532, есть UML, семь примеров Clean Code,
заключение и ссылка на GitHub. После загрузки сохрани и заверши отправку в Moodle.

Код и README находятся в GitHub. Загрузка через браузер оформлена отдельными
коммитами публикации. Четыре исходных локальных коммита разработки сохранены
без изменения в `development-history.bundle` в корне репозитория.

Для запуска после скачивания открой папку проекта в IntelliJ IDEA и запусти
`Main.java`. В терминале можно выполнить `bash run.sh`, а для проверок -
`bash test.sh`; эти команды работают и после загрузки через браузер.

Дедлайн из задания: 12 сентября 2026 года, 16:00.
